## Features

- Basic kernel functionality
- Memory management
- Process scheduling
- File system support
- Basic shell interface

## Prerequisites

To build and run this OS, you will need:

- A system with GCC installed
- QEMU for emulation
- Make

## Installation

Follow these steps to build and run My OS Project:

1. Clone the repository:

    ```sh
    git clone https://github.com/Itamar-Dalal/os.git
    ```

2. Navigate to the project directory:

    ```sh
    cd os
    ```

3. Build the project:

    ```sh
    make
    ```

4. Run the OS using QEMU:

    ```sh
    make run
    ```

## Project Structure

Here's an overview of the project's structure and key components:

- **src/**: Contains the source code for the OS.
- **include/**: Contains header files for the OS, defining structures and function prototypes used across the project.
- **Makefile**: Defines the build process for the OS.
- **iso/**: Contains the iso of the operating system.
